# 공문·기안문 초안 작성

## 입력
사용자가 (1) 주제, (2) 핵심 내용 몇 줄, (3) 서식 파일을 준다.
서식이 없으면 examples 폴더의 가짜 서식은 예시일 뿐이므로
실제 서식을 달라고 먼저 요청한다.

## 작성 규칙
1. 서식의 칸(제목, 관련, 본문, 붙임 등)을 그대로 두고 칸마다 채운다.
2. 사용자가 주지 않은 값(날짜, 금액, 인원, 근거 번호)은
   지어내지 말고 '확인 필요'로 표시한다.
3. 공문서 관례(개조식, '~함', '~바람')를 따른다.
4. 발신기관 주소·전화번호·결재라인은 비워 둔다.

## 마무리
초안 끝에 '살펴볼 규정' 목록을 따로 적는다.
- 내부 규정 파일에서 찾은 것은 규정명과 조항을 쓴다.
- 파일에 없는 법령·규정은 확정하지 말고 '담당자 확인 필요'로 표시한다.

## 주의
examples 폴더의 자료는 모두 가짜다. 실제 업무 내용으로 인용하지 않는다.
